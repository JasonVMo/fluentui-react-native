# Compatibility shim migration

`@fluentui-react-native/design` is the definition site for the theming and styling APIs listed below. The legacy packages remain
available as compatibility shims, but new code should import the corresponding design subpath directly.

| Compatibility package                      | Design subpath                                    | Exported symbols                                                                                                                                                                                                                                                                                                                         |
| ------------------------------------------ | ------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `@fluentui-react-native/theme-tokens`      | `@fluentui-react-native/design/tokens/theme`      | `globalTokens`, `getAliasTokens`, `getShadowTokens`                                                                                                                                                                                                                                                                                      |
| `@fluentui-react-native/theming-utils`     | `@fluentui-react-native/design/theming`           | `getCurrentAppearance`, `isHighContrast`, `mapFontPipelineToTheme`, `mapPipelineToShadow`, `mapPipelineToTheme`, `setIsHighContrast`                                                                                                                                                                                                     |
| `@fluentui-react-native/tokens`            | `@fluentui-react-native/design/tokens/styles`     | `backgroundColorTokens`, `borderStyles`, `borderTokens`, `colorTokens`, `fontStyles`, `foregroundColorTokens`, `getPaletteFromTheme`, `layoutStyles`, `layoutTokens`, `shadowStyles`, `shadowTokens`, `styleFunction`, `textTokens`, `tokenBuilder`                                                                                      |
| `@fluentui-react-native/tokens`            | `@fluentui-react-native/design/tokens/styles`     | Types: `FontDecorationTokens`, `FontStyleTokens`, `FontTokens`, `FontVariantTokens`, `IBackgroundColorTokens`, `IBorderTokens`, `IColorTokens`, `IForegroundColorTokens`, `IShadowTokens`, `LayoutTokens`, `LookupThemePart`, `OperationSet`, `StyleFactoryFunction`, `StyleFactoryFunctionRaw`, `StyleFactoryOperation`, `TokenBuilder` |
| `@fluentui-react-native/use-tokens`        | `@fluentui-react-native/design/use-tokens`        | `applyPropsToTokens`, `applyTokenLayers`, `buildUseTokens`, `customizable`, `patchTokens`                                                                                                                                                                                                                                                |
| `@fluentui-react-native/use-tokens`        | `@fluentui-react-native/design/use-tokens`        | Types: `CustomizableComponent`, `GetComponentInfo`, `HasLayer`, `InjectableComponent`, `TokenSettings`, `TokensFromTheme`, `UseTokens`, `UseTokensCore`                                                                                                                                                                                  |
| `@fluentui-react-native/use-styling`       | `@fluentui-react-native/design/use-styling`       | `applyTokenLayers`, `buildProps`, `buildUseStyling`, `refinePropsFunctions`                                                                                                                                                                                                                                                              |
| `@fluentui-react-native/use-styling`       | `@fluentui-react-native/design/use-styling`       | Types: `BuildPropsBase`, `BuildSlotProps`, `HasLayer`, `RefinableBuildPropsBase`, `RefineFunctionBase`, `ThemeHelper`, `TokenSettings`, `TokensFromTheme`, `TokensThatAreAlsoProps`, `UseStyling`, `UseStylingOptions`                                                                                                                   |
| `@fluentui-react-native/themed-stylesheet` | `@fluentui-react-native/design/themed-stylesheet` | `themedStyleSheet`; type: `NamedStyles`                                                                                                                                                                                                                                                                                                  |

The compatibility packages are located under `packages/shim`. They must contain no implementation beyond explicit named re-exports.
The optional design subpaths above are intentionally not re-exported from the design root.
